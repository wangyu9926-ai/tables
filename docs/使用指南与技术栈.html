01登录、账号与权限

系统没有“游客”形态：未登录只能看到登录页，所有数据接口都要求登录态。

1.1 登录

  • 浏览器打开系统地址（本机是 https://127.0.0.1:8614），输入管理员开通的账号 + 密码。
  • 自签证书部署时浏览器会提示「不是私密连接」：点「高级 → 继续前往」。装过信任包或使用正式证书后不再提示。
  • 连续输错会被锁定（按账号 + 来源 IP 分级限流），等几分钟或让管理员重置。
  • 忘记密码：让管理员在「用户管理」里重置；自己也可以在右上角账号菜单里改密码（改完旧登录凭证立即失效）。

1.2 三种角色

角色能做什么不能做什么
管理员 admin建/删项目与表、字段管理、汇总同步、写入密钥、看板、账号与授权—（权限模型内的最高角色）
可编辑 editor在授权范围内改数据、加行删行、批注、存自己的视图建删表、改列结构（除非被下发「字段管理」能力）
只读 viewer看数据、筛选、导出、写批注、存自己的私人视图改数据、存团队视图、改列结构

权限可以授在项目级或表级。新建账号默认没有任何授权，由创建者在「用户管理 → 授权」里分配，且不能授出比自己更高的角色。

注意：隐藏列不是权限。字段管理里的「隐藏」只影响显示；有这张表读权限的人仍能通过接口拿到隐藏列的值。敏感数据请用「授权」隔离，不要靠隐藏列。

02页面结构：项目 → 表 → Sheet

三层导航：首页是项目卡片，进入项目后左侧是分组，顶部是 Sheet 页签。

  • 新建项目：首页「＋ 新建项目」；项目卡片可重命名、删除（管理员）。
  • 新建表格 / Sheet：项目页或表页的「＋ 新建表格」；Sheet 页签右侧「＋」在当前分组里新建，复制当前 Sheet 的列结构（不带行）。
  • 任意建列：字段管理 →「＋ 新增字段」，选类型（文本 / 数字 / 日期 / 单选 / 多选 / 勾选 / 图片 / 公式）、填选项或公式。
  • 分组与顺序：侧栏分组可双击改名；表名 / 页签长按拖动只调整你自己的顺序（存在本机，不影响同事）。
  • 侧栏收起：「收起 / 展开」把数据表侧栏隐藏，表格全宽。

03编辑单元格与批量操作

交互按 Excel / 表格软件的习惯设计：单击选中、双击编辑、方向键移动、整片复制粘贴。

3.1 编辑

  • 双击单元格进入编辑；选中后按 Enter / F2 也行，直接打字就是替换输入。
  • 编辑中 Tab 提交并右移，Shift+Tab 左移，Esc 取消。
  • 勾选列单击即切换；单选/多选双击弹选项浮层；日期双击弹日历。
  • 数字列可以写 2万、1.8w、4.7万，保存时统一成数值。
  • 每个单元格都带版本号（乐观锁）：你保存时如果同事刚改过这一行，会提示「已被别人改过」，不会覆盖对方。

3.2 区域选择与批量

  • 按住左键拖选一片；Shift+单击或 Shift+方向键从锚点扩展；方向键移动光标。
  • Delete / Backspace 清空选中格（一次请求、可撤销）。
  • Ctrl+C 把整片复制成 TSV，可直接粘回 Excel。
  • 选区右下角的蓝色小方块是填充柄：按住往下拖，按选区第一行向下重复。整片算一次操作，Ctrl+Z 一次撤销。
  • Ctrl+V 粘贴一片：未变化的格子自动跳过；行不够会自动在表尾建行；只复制了一个值却选了一片时，会铺满整个选区。
  • Ctrl+Z / Ctrl+Y 撤销 / 重做自己的改动（批量粘贴算一条）。

3.3 行与列

  • 新增行：「＋ 行」；有筛选/搜索时会先清掉，保证新行可见。
  • 行间插入：悬停最左侧两个行号交界处出现蓝色「＋」，点一下在该位置插入。
  • 拖动行：按住行号上下拖（松手才保存，蓝线指示落点）。行顺序是表数据的一部分，所有人可见。
  • 右键菜单：行上右键可上移/下移、插入、复制这一行、批注、行详情、删除；列头上右键可「按内容适应列宽」、恢复默认、按此列排序。
  • 列宽：拖表头右边界，双击恢复默认（只影响你自己）。

04筛选、排序、搜索与视图

  • 单列筛选：表头漏斗 → 值多选（带计数）/ 日期日历；浮层顶部直接有「升序 / 降序」。选项列还能切「自定义条件…」。
  • 高级筛选：任意筛选浮层底部「高级筛选：多列「且 / 或」…」，一次最多 20 条条件跨列组合，例如 当前阶段 = 已发布 且 合作金额 ≥ 1000。只支持一层组合（全部满足 / 任一满足），不做嵌套。
  • 搜索：工具栏搜索框；排序点列头（▲/▼）。
  • 视图：把「搜索 + 筛选 + 排序」存成命名视图，一键切换（同名覆盖）。自己的视图存在本机、按表分开； 有编辑权限的人还能存团队视图（存服务端、本表所有人可用，只有保存者和管理员能删）。
  • 重置：改动过搜索/筛选/排序后工具栏出现「重置」，一键回到默认视图；分页处始终显示「共 N 行」或「筛选后 N 行（全部 M 行）」。
视图 vs 表：搜索、筛选、排序、列宽、页签顺序都是你自己的；真正共享的是表结构（列、隐藏、汇总规则、看板）和团队视图。

05行详情、批注、图片

  • 行详情：双击最左侧行号，右侧面板按字段类型改整行，改完自动保存；手机端点行号全屏打开。
  • 批注：选中格子后点气泡按钮，或右键「添加 / 查看批注」。有批注的格子右上角显示橙色角标。 批注不算改数据，只读账号也能写；只能删自己的，管理员可删任意。
  • 图片：image 列双击上传，也支持 Ctrl+V 粘贴、拖入、外链；单元格显示缩略图。 单张 ≤ 8MB；每张表图片总量默认 512MB，到顶会拒绝上传，需要先清空回收站。

06汇总同步（子表 → 总表）

把多张子表的数据自动汇到一张总表里，不改变子表任何内容。

  • 入口：总表顶栏「汇总同步」（管理员）→ 选同项目子表 → 逐字段映射；可点「来源表名（自动）」把子表名写进总表某列。
  • 首次保存会把子表已有行全量复制过去（后台执行，界面显示进度）；之后增量同步：子表新增 → 总表追加，修改 → 更新，删除 → 软删。
  • 一个总表可以接多张子表，每张一条规则；总表会用「汇总总表」徽标提示数据来自哪些子表。
  • 双向：在总表里改「镜像行」会回写到子表对应行（冲突时总表优先）；在总表里直接新增的行不覆盖子表；删除镜像行会让子表那行一起软删。
注意：汇总只做字段搬运，不做计算或去重；历史上重复过的数据不会被自动合并。

07数据分析看板

  • 表页顶栏「分析」进入项目级看板：选表、维度、指标、筛选、图表类型（柱 / 条形 / 折线 / 饼 / 表格 / 指标卡），实时预览后保存。
  • 新建看板收在左上角看板下拉里的「＋ 新建看板…」；新建图表只有一个入口，避免多个按钮打架。
  • 看板可以发布到侧栏（按页面组织），同事点开即可看。
  • 分析在浏览器里聚合：单表超过 5 万行时页头会提示「整表加载会慢」，建议先汇总成小表再分析。

08导入、导出与对外写入

8.1 导入

  • 表页顶栏「导入」：支持 .xlsx / .xls / .xlsm / .csv，单文件 ≤ 20MB、≤ 50000 行。
  • 可先预览前几行，再选「追加 / 覆盖 / 新建表」；列映射与列类型可调，表头默认第 1 行。
  • 16 位以上纯数字（订单号、手机号等）会自动按文本导入，避免精度丢失。

8.2 导出

  • 顶栏「导出」下拉：CSV（防公式注入）或 Excel .xlsx（表头加粗冻结、列宽沿用表设置、公式列给算好的值）。

8.3 对外写入（脚本 / RPA）

  • 表页「写入密钥」（管理员）生成表级密钥；脚本调 POST /api/in/<表ID>，带 X-KB-Token 即可免登录插入，单次 ≤ 1000 行。
  • 要防“重试插重”，再加 X-Idempotency-Key: 你的业务单号：同一个键重试直接返回上次结果，不重复插入（7 天窗口）。
  • 密钥只对所属表有效，只能插入：不能读数据、不能改结构；随时可作废，立即生效。

09变动历史与实时协作

  • 变动历史：顶栏「变动历史」按「谁 · 时间 · 做了什么」显示，包括旧值 → 新值；接口写入、密钥、汇总回写这类系统动作也会翻成人话。
  • 实时刷新：页面开着某张表时，同事一改，约 0.1–0.2 秒内出现，而且只重画变的那几行，滚动位置不动、输入框不会被冲掉。
  • 断线会退回每 5 秒轮询；重新连上后自动恢复推送。
  • 两个人同时改同一格：后保存的人会收到「已被别人改过」的提示，由服务端版本号裁决，不会静默覆盖。
  • 切到别的窗口再切回来，会静默刷新当前页（4 秒内不重复请求）。

11总体架构

单进程 Python 应用 + MySQL；浏览器只与本机/内网的一个端口通信，登录态在网关层统一校验。

浏览器（原生 JS，无构建，12 个模块脚本）
   │  HTTPS（或反向代理终结 TLS）
   ▼
登录网关 auth_gate
   ├─ Cookie 签名校验（HMAC-SHA256）· scrypt 口令 · 失败锁定 / 限流 · 同源写保护
   ├─ 内容安全策略（脚本按 sha256 哈希放行）· 安全响应头
   ▼
FastAPI 应用（backend/app.py 装配层）
   ├─ modules/*.py   按功能的路由（表 / 列 / 行 / 视图 / 导入导出 / 同步 / 看板 …）
   ├─ deps.py        共享层：进程内缓存、权限、JSON、缓存失效
   ├─ engine.py      建表、CRUD、公式引擎（AST 白名单）
   ├─ sync.py        汇总同步队列（子表 ↔ 总表）
   └─ changes.py     变更日志 + SSE 推送
   ▼
MySQL 8（utf8mb4）· kb_* 表

所有列表/单元格请求都经过同一套权限检查（项目级/表级 × 只读/可编辑），写操作写审计并推送到打开这页的浏览器。

12技术选型

选型原则：依赖少、可直接拷走部署、局域网/服务器都能跑、无需前端构建链。
层选型为什么
运行时Python 3.11依赖成熟；Windows 双击启动与 Linux systemd 都能用
Web 框架FastAPI + uvicorn类型化接口、自动校验、SSE 流式响应简单；单进程即可支撑内网并发
数据库MySQL 8（utf8mb4）行存 JSON + 事务 + 成熟的运维/备份工具链
数据访问PyMySQL + 自建连接池无重框架；连接池按进程复用，空闲连接探测存活
导入导出pandas / openpyxl / xlrdExcel 兼容性最稳；只在导入导出时按需加载
前端原生 JS + CSS（无框架、无构建）直接由静态目录提供，改完刷新即生效；避免前端工具链成为部署负担
实时SSE + 轮询兜底单向推送够用，比 WebSocket 简单、穿代理更稳
安全哈希 CSP、HMAC Cookie、scrypt不引入额外依赖，策略可随页面内容自动计算

15关键机制

15.1 公式引擎

支持同行字段引用与同项目跨表 LOOKUP / SUMIF / COUNTIF / AVGIF / MAXIF / MINIF。表达式用 Python AST 白名单求值（只允许算术、比较、字符串/日期函数），并做了嵌套重复、可空重复等灾难性写法预检查与长度上限。表/组改名会同步更新公式里写死的表名引用。

15.2 并发与一致性

  • 行级版本号：UPDATE … WHERE id=? AND ver=?，冲突返回 409，前端提示刷新。
  • 批量写接口逐行返回「更新 / 新建 / 版本冲突 / 报错」，一行失败不影响其它行。
  • 汇总回写带线程内防循环标记；总表与子表冲突时总表优先。
  • 删除一律软删，事后可由清理工具按天龄物理删除。

15.3 缓存与失效

  • 元信息（表/列/权限视图）与行数据都缓存在进程内，写操作按路径精确失效，避免每次读都付远程库的往返。
  • 缓存是进程内的：多实例部署会各看各的缓存，所以不支持多实例同时写同一库。

15.4 实时刷新

每次写入递增该表的变更序号并广播事件；浏览器只取变的那几行（按 ID），只重画对应 <tr>。因此“改动→上屏”通常 100–200ms，且不影响滚动与未保存的输入。

15.5 内容安全策略（CSP）

脚本只放行同源外部文件（主页面 12 个 js）与按内容 sha256 哈希的内联块（登录页、用户管理页）。页面里出现 onclick="…" 这类内联事件不会被执行；服务端只记错误、不会自动放宽策略。

16安全设计

面做法

18部署、备份与测试

18.1 部署

  • 本机 / 局域网：双击单一的启动脚本，首启向导会问数据库连接和管理员账号，然后自动生成自签证书并以 HTTPS 监听。
  • 服务器 + 域名：nginx / Caddy 终结 TLS → 应用只监听 127.0.0.1；配置 GATE_HTTPS=1（Secure Cookie + HSTS）、SSE 关缓冲、时区 GATE_TZ；systemd 常驻。
  • 升级：拉取新代码 → 重启一次；表结构在启动时幂等补齐（schema_version 可查），已有数据不动。

18.2 备份与清理

  • 备份脚本：mysqldump --single-transaction，压缩保存、默认保留最近 7 份、校验文件完整性；口令通过环境变量传入，不出现在命令行。
  • 恢复：先停服务 → 备份当前库 → 导入 dump → 启动后抽查表/行/账号/汇总规则。
  • 清理：软删的行/历史/回收站图片可按天龄物理删除（默认只统计，--yes 才动手，删前先备份）。

18.3 测试

  • 上线前回归 365 项断言：登录与访问控制、增删改查与乐观锁、公式、筛选、导入导出、视图、幂等键、汇总同步与双向回写、SSE、CSP、畸形输入（只能 4xx 不能 500）。
  • 回归只写 __pretest__ 前缀的临时数据，退出自动清理；默认拒绝连生产库，需显式放行。
  • 另有只读模糊测试（数千个畸形请求 0 个 5xx）、真实备份恢复演练、Linux 容器整轮回归。

19常见问题

打不开登录页 / 提示「不是私密连接」

自签证书的正常提示：点「高级 → 继续前往」。想彻底不提示，把服务器证书装进「受信任的根证书颁发机构」（当前用户即可），或改用域名 + 正式证书。

登录提示被锁定

连续输错触发限流，等几分钟再试；确认账号是管理员开通的那个，忘记密码让管理员重置。

看不到某张表 / 某个项目

没有授权。找管理员在「用户管理 → 授权」里加项目级或表级权限；新建账号默认无任何授权是设计如此。

筛选后「数据不见了」

多半是筛选/搜索挡住了：分页处会显示「筛选后 N 行（全部 M 行）」，点工具栏「重置」即可恢复。

粘贴时提示行数太多 / 没反应

粘贴会自动在表尾建行，超过 500 行界面会自动分批；如果目标列是公式列或图片列，会被跳过。

公式不刷新 / 显示旧值

公式由服务端计算，保存后立即生效；若页面长时间未动，刷新一次（或等实时推送）。汇总同步的总表由后台队列写入，界面会显示进度。

导入或导出报「服务器缺少 pandas / openpyxl」

服务器依赖没装全：在项目目录执行 pip install -r requirements.txt 后重启一次服务。

端口被占用 / 窗口一闪就关

已经有一个实例在跑：关掉旧窗口或换端口再启动；启动脚本必须是 GBK + CRLF（仓库已固定），不要另存成 UTF-8 / LF。

多人同时改同一格

后保存的人会收到「已被别人改过」，刷新后重新提交即可——这是故意的，避免互相覆盖。
